# 文明 · 社会主义核心价值观 —— 演示文稿（单文件 deck）

## 使用

- 直接双击打开 `index.html`（任何现代浏览器），或把整个文件夹拖进 GitHub Pages。
- **翻页**：`←` `→` / 空格 / 回车 / PageUp / PageDown；`Home` 回封面，`End` 到末页；数字键跳页（如按 `2` `4` 到第 24 页）；触屏左右滑动；右下角圆钮也可翻页。
- 画布 1920×1080，浏览器窗口任意大小时自动等比缩放 + 居中留边。
- 当前页码存在 localStorage，刷新后回到上次位置。
- 系统开启「减少动态效果」（prefers-reduced-motion）时，全部动效自动关闭，静态排版完整可读。
- 零 CDN、零外链字体/图标/图片，断网可用。

## 技术

- 单文件 HTML：外壳负责等比缩放、翻页、页码与进度条（单页不自带页码，第 02 页按约定不渲染页码）。
- 动效全部手写 CSS/SVG/JS：文字逐字跳出（`transition-delay` 逐字错开）、SVG 线条生长（`stroke-dashoffset` + `pathLength` 归一）、数字滚动（`requestAnimationFrame`，滚到真值停住，翻回重播）、柱条长出（`scaleY`）、封面「文」字四笔描出后落珊瑚红小印（全篇签名细节）。
- 缓动统一 `cubic-bezier(.22,1,.36,1)`；一页一个主运动 + 少量环境微动（漂浮小装饰）。
